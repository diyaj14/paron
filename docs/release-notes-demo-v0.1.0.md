# Paron Android Demo v0.1.0

Installable Android demo APK for the Paron wallet.

## Setup

Install on Android 8.0 (API 26) or newer. On first launch, open **Backend Server Address**, enter the deployed Render API gateway URL, and tap **Apply Server URL**.

This is a debug/demo build, not a production-signed app. Do not use it for real payments or real customer data. PayPal integration uses Sandbox.
