What is real in this demo?

Local simulation: wallet, signed receipt, merchant inbox, and settlement are example data held in this browser only.

Connected backend: sign-in, account balance, token reservation, PayPal Sandbox approval/capture, sync submission, and transaction status can call the configured API gateway. A sync response may be queued; only a backend status of SETTLED is shown as settled.

Hardware/transport: this website does not use Android secure hardware or a physical BLE merchant terminal. Use the linked Android APK to show the device app.
