**Do not redesign, modernize, simplify, or reinterpret my UI. Implement the provided design as faithfully as possible.**

## 3. Technology and Architecture

Implement the application as a native Android app using **Kotlin**.

- Use Jetpack Compose if the existing project supports it; otherwise, inspect the current project and retain its established UI framework.
- Follow a maintainable architecture, preferably MVVM with a clear separation between UI, state management, business logic, and data access.
- Use reusable composable functions or UI components for repeated elements such as buttons, merchant rows, balance cards, headers, and transaction items.
- Use a centralized theme for colors, typography, shapes, and spacing.
- Handle Android system bars, screen insets, keyboard visibility, scrolling, and different device sizes properly.
- Use state-driven UI instead of hardcoded visual states.
- Keep the code modular, readable, and easy to extend.

Do not replace the design with generic Material components whose default styling differs from the reference.

The app should follow the supplied flow:

- When an internet connection is available, use the existing UPI payment path.
- When an internet connection is unavailable, present the offline-token payment option.
- Display the relevant payment amount and merchant details before confirmation.
- Represent offline transactions as locally recorded and awaiting verification when appropriate.
- Reflect transaction status and balance changes consistently across the relevant screens.
- Handle loading, errors, retries, cancellation, and navigation without breaking the intended UI.

Keep the visual treatment of each state consistent with the provided design system.

**Important:** Do not simulate a successful real-world payment merely by displaying a success screen. Keep payment processing separate from UI presentation and use the appropriate payment-provider integration or clearly identified development-mode behavior. Offline payment authorization, token validation, and later reconciliation must follow a secure backend protocol.
